# yourshop

## Printerest is a platform that lets users upload images, like them, leave comments, and authenticate their accounts. The app provides social media-like features with a focus on sharing and interacting with images.
[Visit the live site](https://printerest-frontend.onrender.com/)
## Features
- **User Authentication:** Secure sign-up and login functionality.
- **Download:** Users can download images they like.
- **Image Upload:** Users can create a profile and upload their own images.
- **Like & Comments:** Users can interact with images by liking them and leaving comments.


## Technologies Used
**Frontend:**
- **React.Js**
  
  **Packages Used**
   - Redux (state management)
   - React Router DOM
   
 - *Host*
[Netlify](https://www.netlify.com/)

**Backend:**
- **Node.js / Express.js / MongoDB**
- Authentication:  JWT
- Post Uploads: Integration of Cloudinary for storing images 
**Packages Used**
- bcrypt (for password hashing and comparison)
- cloudinary (cloud storage for media files)
- multer (for file uploads)
- mongoose (for MongoDB object modeling)
- nodemailer (for email notifications)
 - *Host*
[Render]( https://render.com/)
  
   **DataBase:**
   - MongoDB(storing user data, posts, comments, likes)
